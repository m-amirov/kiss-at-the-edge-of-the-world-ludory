- `s02-career-choice` предлагает ровно три взаимоисключающих варианта:
  - `people` → `career-thesis-people=true`;
  - `place` → `career-thesis-place=true`;
  - `own-choice` → `career-thesis-own-choice=true` и `damir-direct=true`.
- Эти булевы флаги — сохраняемое представление литературного `careerThesis=people|place|own-choice` в поддерживаемой схеме Ludory N1. При следующих сценах следует интерпретировать их как одно каноническое значение и не смешивать с романтическим `routeIntent`.

## Решение и открытый риск

Ludory N1 допускает `flag_set` только с булевым значением. Три флага `career-thesis-*` использованы как взаимоисключающее представление `careerThesis` вместо изменения фреймворка и save schema. Для дальнейших сцен нужен единый читатель этого значения; иначе возможны несогласованные отложенные отклики S03/S09/S66. Не создавать второй независимый источник состояния.

**Важно — прежний M2 checkpoint несовместим.** Независимое ревью воспроизвело, и отдельная проверка подтвердила: сохранение завершённой M2-версии на `s01-common/beatIndex=1` теперь отвергается как `state: invalid beatIndex`, поскольку технический `s01-m2-end` удалён для перехода к S02. Базовый launcher не переписывает такое сохранение автоматически, но для продолжения потребуется явный Restart. M2 не публиковался; утверждённое проектное решение исключает импорт старых сохранений без отдельной схемы совместимости, поэтому риск оставлен открытым. До релиза требуется согласованное решение о namespace/миграции, не обещать save compatibility.
