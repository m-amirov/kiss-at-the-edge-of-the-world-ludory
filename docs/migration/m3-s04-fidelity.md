- Две литературные развязки S03 (`message`, `silence`) теперь обе переходят в S04; предыдущая техническая концовка S03 удалена.
- **Авторский S04-C1**: разрешить короткую запись / попросить убрать камеру / предложить групповое фото.
  - `accepted → consent-camera-accepted=true`;
  - `declined → consent-camera-declined-respected=true`;
  - `negotiated → consent-camera-negotiated=true`.
- Три взаимоисключающих булевых флага — поддерживаемая схемой N1 сериализация исходного `consent.camera=accepted|declined_respected|negotiated`. Романтический `routeLock=null`; не добавлены неавторские эффекты affinity, camera hardware и фотоальбом без готового ассета/прав.
- Все варианты сходятся в полную `s04-common`. Отложенный авторский отклик зависит от S03-C1 (`s03-damir-message/silence`): ровно одно из двух окончаний S04 доступно. Никакие другие флаги не меняются.
- Предикатная техническая кнопка **«Продолжить»** требуется для перехода к соответствующей авторской реакции из-за ограничения Ludory N1 1.2.2 (условный переход/обычная реплика не поддерживаются). Это дополнительное нажатие, не сюжетное решение. Требуется UI-приёмка позднее.
