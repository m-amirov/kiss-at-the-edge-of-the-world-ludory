Тесты проверяют отсутствие любых premium-атрибутов S08: Ludory Economy E5 остаётся выключенной для первой игры.

**Границы доказательств:** локальный `npm test` и синтаксис проверяются для текущего коммита отдельно; GitHub CI, браузерная/мобильная приёмка, реальные Яндекс/VK SDK и F5b2 ZIP для S08 остаются **NOT_RUN**. Исторические Yandex/VK ZIP/receipts относятся только к более раннему срезу S05. Studio CLI в этой среде не приняла сведения о компонентах (`Invalid component state fields` — несовпадение схемы состояния с установленной Studio); обход ownership/trust или принудительное обновление компонентов не проводился.
