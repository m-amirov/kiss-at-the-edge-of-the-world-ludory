S11 — обязательная общая сцена: Ник хочет снять эффектный кадр, Эрик замечает опасную линию прибоя, Алиса выбирает безопасную реакцию. Во всех вариантах группа остаётся в безопасной зоне; текст, поведение и концовки взяты из рукописи, не из старой демоверсии.

## Граф и смысл согласия

- `s10-common` теперь ведёт непосредственно в `s11-intro`; старая техническая концовка `s10-m3-end` удалена.
- `s11-consent-dispatch` — только техническое «Продолжить», **без эффектов**: старые `consent-camera-accepted|declined-respected|negotiated` от S04-C1 выбирают одно из трёх авторских вступлений. Неподходящий guard отвергается.
- **Согласие из S04 не переносится** на новую съёмку в S11. Во всех авторских исходах Алиса не даёт согласия на запись своего лица/голоса; не создаётся нового permission-grant.
- Авторский **S11-C1** бесплатно предлагает A («Предложить безопасную точку…»), B («Попросить всех уйти…») или C («Сначала разобраться с правилами…»):
  - A: `beachFootage=safe_only`, `nickSafetyResponse=changed_position` → `beach-footage-safe-only`, `nick-safety-changed-position`.
  - B: `beachFootage=none`, `nickSafetyResponse=deleted` → `beach-footage-none`, `nick-safety-deleted`.
  - C: `beachFootage=safe_only`, `nickSafetyResponse=asked_then_reframed` → `beach-footage-safe-only`, `nick-safety-asked-then-reframed`.
- Два смысловых поля рукописи представлены взаимно исключающими булевыми flags N1, чтобы Back и `actionLog` воспроизводили их детерминированно. Дополнительных романтических очков, `routeLock`, платных решений, IAP и rewarded-рекламы нет.
- Ветви сходятся в `s11-common-b`, который теперь ведёт непосредственно в `s12-intro` ([точный перенос S12](m3-s12-fidelity.md)). Исторический срез S11 временно завершался технической `s11-m3-end`; она удалена после интеграции S12. Старое неопубликованное Draft-сохранение на такой удалённой концовке может потребовать явного Restart; совместимость не доказана.
