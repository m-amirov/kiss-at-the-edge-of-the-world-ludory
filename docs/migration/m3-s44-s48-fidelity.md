## Ограничения

**Литературный Minor, не дефект переноса:** в S48 Эрик передаёт Алисе забытую закладку, а в альтернативе S44-C1-B он вручает закладку с деревянной птицей ещё раз. Уточнение, один это предмет или два разных, требует авторского решения; дословный закреплённый текст самостоятельно не редактируется. Это особенно заметно при выбранной игровой хронологии S48 → S44.

Семь сюжетных идентификаторов концовок **не означают релизную готовность**. Проверка английской локализации, авторских медиа и прав, состояния компонентов Ludory Studio, экспорта VK/Яндекс, фактических браузера/мобильного устройства, Save/Reload в UI, CI, модерации и публикации — отдельные открытые gates. При старых черновых сохранениях на удалённых технических сценах миграции пока нет; требуется явный Restart при несовместимом snapshot. История Back после reload в N1 не гарантируется.

Изменения предназначены только для существующего **Draft PR #2**. `main`, публикацию, исходный репозиторий и режим Draft не изменять.
