# M3 — S66 «Hveragerði, день 4. Ряды под стеклом»

**Источник:** `m-amirov/kiss-at-the-edge-of-the-world@1e775f1fcd5269b2574b5a120a1f4f6f716ebb8c`, `content/season-1-vertical-slice-episodes-01-02.md`, от заголовка S66 до конца закреплённого файла.

S66 продолжает историю непосредственно после всех трёх авторских исходов S08-C1. Нового художественного выбора нет. Авторские условные фрагменты делятся по уже установленным флагам:

- S08-C1 `damir-care-warm|neutral|personal` → отдельный короткий эпилог на кухне.
- S02-C1 `career-thesis-people|place|own-choice` → соответствующий текст абзаца Алисы для Марины.
- Между ними и после них — неизменённое общее повествование. Технические `Продолжить` (`s66-damir-dispatch`, `s66-career-dispatch`) не изменяют состояние и не являются новыми авторскими решениями.

## Проверки и ограничения

`tests/m3-s66.test.mjs` проверяет девять SHA-256, граф двух точных условных переходов, три реальные комбинации предыстории S02/S08, отказ от чужих callback, Back, JSON-продолжение, сохранение флагов и отсутствие premium/economy. `tests/m3-s08.test.mjs` регрессионно подтверждает новый переход S08→S66.

Внутренняя валюта, premium choices, rewarded, IAP и route lock **выключены для первой игры**. Ludory Economy E5 остаётся отдельной opt-in возможностью будущих проектов.

Старые неопубликованные сохранения с технической остановкой `s08-m3-end` могут потребовать явный Restart: формальная миграция таких сохранений не реализована. Back после полной перезагрузки страницы не гарантирован существующей памятью N1. Пользовательские данные не удаляются автоматически.

**Release gates:** Studio component schema conflict (`Invalid component state fields`, schema 1/2) не обходился; Yandex/VK ZIP+receipts для S66, браузеры/мобильные устройства, SDK, художественные ассеты/права, локализация EN, CI и настоящая модерация **не подтверждены**. Исторические ZIP/receipts проверяли только старый срез S05. PR остаётся Draft, `releaseReady=false`, `publicationAllowed=false`.
