# M2 — Входные критерии нативного вертикального среза

Основание: [M1 inventory](m1-inventory.json), [canon/parity matrix](m1-canon-parity.md), [M1 evidence](m1-evidence.md), [проектное решение](../superpowers/specs/2026-11-03-kiss-ludory-migration-design.md). Это критерии **следующего** PR, не отчёт о проведённых проверках.

## Нативный каркас

- [ ] Закрепить совместимый SHA/tag Ludory и Node.js 22+; записать причину изменения pin, если он изменится после M1.
- [ ] Через Studio `create` preview проверить список создаваемых файлов в **новом пустом** рабочем каталоге, затем применить только профиль `narrative-game` + шаблон `narrative-interactive` с Yandex/VK target IDs.
- [ ] Проверить `ludory.project.json`, `components status` и отсутствие CEOS/Starter Kit зависимостей, `.codex-os`/исторических run records и любых правок исходного репозитория.
- [ ] Сохранить точно один выбранный канонический отрывок S01 (текст из литературы, не из `src/season-data.js`) с явными `beatId`, сценой, следующим переходом и одним содержательным выбором; не подменять текст демонстрационными заглушками.

## Поведенческие gates

- [ ] Автоматический тест: S01 → разрешённый выбор → ожидаемый следующий beat/scene и наблюдаемое последствие; повторное действие не начисляет эффект дважды.
- [ ] Автоматический тест: сохранение внутри сцены → reload → тот же beat, доступные выборы и state; повреждённый/чужой state не восстанавливается молча.
- [ ] Автоматический тест: Back возвращает полный snapshot, включая narrative state, а последующий повтор выбора детерминирован.
- [ ] Проверить в браузере wide 1000×720 и portrait 390×844: нет перекрытия текста/кнопок, выделение выбора и диалог читаемы, navigation работает мышью и касанием. Браузерная эмуляция не считается тестом физического телефона.
- [ ] Музыка не начинается автоматически без жеста пользователя; для M2 допустим один проверенный локальный sample либо её отсутствие с явной отметкой.

## Платформенный вход без преждевременного релиза

- [ ] Убедиться, что launcher соответствует неизменённому шаблону Studio; не вводить внешние ресурсы, произвольные `src/` media paths или CSS `url()`/`@import`, запрещённые F5b2.
- [ ] Проверить programmatic `planNarrativePlatformExport`; только если `READY_TO_DERIVE`, построить две локальные тестовые ZIP в отдельном output каталоге и проверить receipts и SHA-256.
- [ ] Сохранить evidence Yandex/VK mock-SDK отдельно от игры; выпуск, реальная модерация и публикация остаются `NOT_RUN` и `releaseReady:false`.

## Решения владельца — не блокируют M2

1. Перенос прогресса старых игроков: отдельно согласовать перед реализацией save-совместимости. M2 допускает только новый save namespace.
2. Свободный текст в сообщениях: текущий Ludory N1 поддерживает конечные авторские варианты. Другая семантика — отдельное расширение, не скрытая часть M2.
3. Полный перенос арт/OST: M2 не копирует массово ресурсы; права и корректность media mapping — M4.

## Критерий готовности перехода в M3

M2 принимается только при наблюдаемых green тестах S01/choice/Back/save/reload, доказательстве двух viewport-состояний и сохранённом журнале всех негативных проверок. Локальные ZIP опциональны при ограничении экспорта, но их невозможность фиксируется как blocker M6, а не замалчивается. Ни один `PASS_LOCAL` не подтверждает готовность к публикации.
