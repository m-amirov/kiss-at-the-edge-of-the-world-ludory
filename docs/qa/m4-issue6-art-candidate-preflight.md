# M4 Issue #6 — проверка исходной иллюстрации и кандидата ретуши

Предназначение: **проверить пиксельную сохранность** ретушированного портретного PNG перед независимой художественной приёмкой. Скрипт не заменяет ассеты, не меняет source mapping и не переводит `artStatus` в `approved-independent`.

## Использование

```powershell
node tools/m4-art-candidate-preflight.mjs `
  --source game-studio/assets/vis-s38-alice-nick-ordinary-day-portrait-v2.png `
  --candidate D:/art-review/vis-s38-nick-no-camera-candidate.png `
  --mask D:/art-review/S38_no_camera_mask.png `
  --source-sha256 fa2b4e6aad5d2a5a482f9b2ca8e2954dfad76b6b188729f1411d6ad9de9dfd2e `
  --report D:/art-review/S38-preflight.json
```

Использовать **реальные исходные PNG 1024×1536**, не уменьшенные браузерные скриншоты. Местоположение масок — в подготовленном пакете Issue #6; маски не являются готовыми кандидатами. Белые пиксели обозначают допустимую зону редактирования, чёрные — неизменяемый исходник. Границы масок перед инпейтингом необходимо проверить вручную: существующие маски — только начальные ориентиры.

## Что проверяется

1. Корректная структура PNG (заголовок, чанки, CRC-32, zlib-данные, построчное восстановление фильтров).
2. Поддерживаются несжатые по битовой глубине (8-bit) неинтерлейсные RGB/RGBA и grayscale PNG.
3. SHA-256 **исходного файла** строго совпадает с закреплённым provenance-манифестом.
4. Совпадение размеров исходника, кандидата и маски; исходник не меньше 1024×1536.
5. Маска покрывает не менее 0,01% и не более 25% изображения.
6. Кандидат действительно меняет хотя бы один пиксель внутри маски, **ни один пиксель вне маски не меняется**. Пересохранение всей сцены генератором без последующего исходно-идентичного композитинга не пройдёт этот gate.

Успешная проверка возвращает `CANDIDATE_ONLY_NOT_ART_APPROVED`, **не художественный PASS**. Этот gate не определяет, не искажены ли лица *внутри* маски, анатомия кистей, детали камеры и ремней, свет, права на модификацию или соответствие конкретному текстовому моменту. Для этих свойств нужны отдельная визуальная оценка, provenance, мобильные скриншоты и браузерный QA.
