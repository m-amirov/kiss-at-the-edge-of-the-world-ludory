## Не пройденные release gates и реальные ограничения

1. **Браузер/мобильный UI — BLOCKED в текущей среде.** Установленный Playwright нашёл Chromium, но запуск `/usr/bin/chromium --headless --no-sandbox` завершается `process_singleton_posix.cc: socket() failed: Operation not permitted (1)`. Повышенные sandbox-права запрещены политикой. Общий cloud-браузер при открытии `http://127.0.0.1:8765` вернул `ERR_CONNECTION_REFUSED`: его `localhost` не относится к namespace игрового сервера. Никакой обход разрешений не предпринимался. Поэтому отображение на 390×844 и 1000×720, клики, Save/Reload/Back в UI, скриншоты и доступность **NOT_RUN**, а не PASS.
2. **Только текст, без графического наполнения.** `game/narrative-assets.json` содержит `assets: {}`, экспорт `assets` в `game/src/story.js` тоже пуст. В графе нет beat-типов `photo`, `keepsake` и `message` (только dialogue/choice/ending). Литературные упоминания фотографии/сообщений **не** являются интерактивными механиками. Это продуктовый пробел относительно утверждённой концепции, не ошибка проверки миграции текста.
3. **После Reload нет истории Back.** История находится в замыкании `createNarrativeRuntimeUpdate` и не входит в сохраняемый `narrative` snapshot. Персонаж, выборы и прогресс восстанавливаются; возврат назад после новой загрузки — отдельный продуктовый контракт.
4. **Studio доверие/экспорт — BLOCKED/NOT_RUN.** `game/ludory.components.json` — схема 2, managed-хеши всех четырёх файлов фактически совпадают с диском. `game/ludory.studio.json` — историческая схема 1 / шаблон 1.2.0. Исполняемый `ludory` в PATH отсутствует; нельзя приписывать root cause конкретному полю схемы без запуска актуального Studio. Не копировать и не подделывать trust-рецепты. Yandex/VK ZIP для полного графа не собирались.
5. **Локализация/медиа/площадки — NOT_RUN.** `en` для сюжетных реплик — русский fallback; прав и источников реальных медиа нет; CI удалённого PR и выпускные артефакты не проверялись на этой ревизии. Реальная модерация площадок не входит в согласованный объём.

Авторская неточность «закладка Эрика выдана дважды» (S48 → вариант S44-C1-B) остаётся в [fidelity S44–S48](../migration/m3-s44-s48-fidelity.md); канонический текст без согласования не редактировался.
