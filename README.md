# Поцелуй на краю света — Ludory

Новый проект для чистого переноса визуальной новеллы на [Ludory](https://github.com/m-amirov/ludory).

- Исходная игра: https://github.com/m-amirov/kiss-at-the-edge-of-the-world
- Фреймворк: https://github.com/m-amirov/ludory
- Статус: M1 завершён; M2 в разработке — нативный runtime Ludory и полный S01 с тремя вариантами посадки. Это **не** полный EP01, EP02–EP10 не перенесены.
- Исходный проект и его история остаются неизменными; CEOS/Starter Kit не являются зависимостями нового проекта.

Никаких заявлений о релизной готовности или публикации до прохождения соответствующих проверок.

## Локальный сценарный срез M2

`game/` создан официальным Studio-шаблоном `narrative-interactive` из закреплённого Ludory. Для запуска в браузере из корня репозитория: `python3 -m http.server 8080 --directory game`, затем `http://localhost:8080`. Для тестов: `npm test` (или `npm run test:m2`). Сервер нужен лишь для HTTP-раздачи статических файлов — backend игры не требуется.

**Ограничения M2:** стандартный неизменяемый `game/src/main.js` при запуске показывает демонстрационный заголовок «Вечер у маяка» и разрешает переключиться на ещё не переведённый английский; изменить его без нарушения текущего контракта F5b2 нельзя. Авторская замена `story.js` и удаление демо-изображений отражаются как `CONFLICT` в Studio `components status` — перенастройка доверия вручную не производится. Эти ограничения необходимо устранить в Ludory до приёмки полноценной игры. На другом хосте штатная проверка Studio ownership потребует отдельного доверенного переноса.
