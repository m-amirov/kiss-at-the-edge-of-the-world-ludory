# Поцелуй на краю света — Ludory

Новый проект для чистого переноса визуальной новеллы на [Ludory](https://github.com/m-amirov/ludory).

- Исходная игра: https://github.com/m-amirov/kiss-at-the-edge-of-the-world
- Фреймворк: https://github.com/m-amirov/ludory
- Статус: M1 завершён, M2 — нативный проект Ludory; **M3 в работе** — авторские S01 → S02 → S65 → S03 → S04 → S05 с условиями, выборами и регрессионными тестами. Эпизод 1 присутствует как последовательность исходных сцен, но полноценная приёмка и медиа не завершены; S06 и последующие сцены пока не перенесены.
- Исходный проект и его история остаются неизменными; CEOS/Starter Kit не являются зависимостями нового проекта.

Никаких заявлений о релизной готовности или публикации до прохождения соответствующих проверок.

## Локальный сценарный срез Ludory

`game/` создан официальным Studio-шаблоном `narrative-interactive` из закреплённого Ludory. Для запуска в браузере из корня репозитория: `python3 -m http.server 8080 --directory game`, затем `http://localhost:8080`. Полный набор тестов: `npm test`; `npm run test:m2` запускает только исторические проверки S01. Сервер нужен лишь для HTTP-раздачи статических файлов — backend игры не требуется.

**Актуальная техническая база:** Ludory Studio `narrative-interactive` 1.2.2; на проверенном хосте `components status = IN_SYNC`, runtime использует название игры из манифеста, авторские модули находятся вне управляемого шаблона. Английские реплики пока являются копией русского текста — это не готовая локализация. Для условных сцен N1 нужны дополнительные технические кнопки «Продолжить», пока нет автоматического перехода по predicate. Сохранения предыдущих неопубликованных черновиков на удалённых технических концовках могут потребовать явного Restart; версии/миграция saves должны быть утверждены до релиза.

Проверены **локальные** сценарные тесты и парные Yandex/VK ZIP + receipts; браузерный UI, фактический Save/Reload на устройствах, ассеты/права, GitHub CI и площадочная модерация не являются пройденными release gates. На другом хосте Studio ownership/trust требует штатной настройки, а не копирования доверия из Git.
